El trabajo final de Programación de Software es presentado acorde a la inscripción realizada ante el profesor
Individual o en grupo de dos estudiantes (No es permitido divorcios, ni adición de otro estudiante después de
asignado trabajo por cualquier motivo) y debe contemplar los siguientes parámetros:

 Fecha de entrega enunciado del proyecto por el docente: octubre/29 de 2026.
 Debe realizarse bajo las mismas características de lo practicado y enseñado en clase.
 El proyecto debe de realizarse para un ambiente WEB Cliente/Servidor con servicio Web API Core, en ASP.NET

    utilizando los lenguajes: C#, JavaScript con JQuery, Html y Bootstrap en la versión Visual Studio 2026 donde se
    realizaron las prácticas durante el semestre e instalada en el ITM.
 El proyecto debe cumplir con la programación por capas (mínimo 3) desde formularios HTML controladas por
    páginas JavaScript para cada formulario, el CRUD debe de estar siendo aplicado desde servicios web API
    implementados con Entity Framework Core.
 En el proyecto de servicio API web debe implementarse con el modelo Entity Framework para la conexión y la
    realización de las transacciones en la Bases de datos, el llenado de DataTables, listas desplegables (combos) y otros
    objetos utilizados en la asignatura que considere utilizar.
 Debe contener un formulario Splash que dure aproximadamente 4,5 segundos con diseño acorde al proyecto a
    realizar. (Contener como mínimo: Titulo del proyecto, Logo, integrantes del proyecto como desarrolladores, Fecha,
    etc.)
 Debe contener un formulario de ingreso (login) que permita capturar el usuario y la clave, validarla en la base de
    datos y permitir o no el ingreso al sistema. Utilizar variables tipo sesión para mostrar el nombre del logueado y su id
    oculto en las páginas.
 Debe tener un menú principal que permita navegar entre todos los formularios realizados en el proyecto. Nota:
    Deben de estar todos los formularios operativos y maestros con sus respectivas opciones de manejo (con sus objetos
    y clases locales), los formularios son basados para su frontEnd desde el modelo relacional de la base de datos.
 En cada formulario a implementar tener en cuenta las siguientes consideraciones:
     Un sistema de menú que permita el consultar, agregar, modificar, cancelar e imprimir.
     El formulario debe contener el JS con JQuery que realice las tareas propias del objetivo de cada formulario,

        utilizando los servicios API web (Get, Put, Post y Delete).
     En el proyecto debe contener todos los objetos vistos en clase.
     Todo formulario operativo debe de contener un DataTable que muestre todos los datos respectivos de la tabla

        controlada.
     Solo implementar completamente 4 formularios: el splash, el login y los 2 que son asignados por el docente al

        momento de la aprobación del proyecto en la asesoría de aprobración del proyecto. El resto de los formularios
        solo deberán contener todos los objetos propios necesarios para su implementación posterior (prototipo) como
        se vio en la guía de la práctica.
 Toda la información debe estar contenida en una base de datos SQL Server 2005/2012/2015 o superior
     Debe crearse manualmente el script para la creación de la base de datos (como la vista en clase), las instrucciones
        para las relaciones entre las tablas (PK/FK) y se requiere el insert de los datos en cada tabla para el buen
        funcionamiento inicial del proyecto. (Debe ejecutar sin errores al momento de la sustentación)
     El Modelo relacional de la base de datos debe estar normalizado hasta una 3ra. forma normal como mínimo.
     Toda transacción o procedimiento en la base de datos debe de estar en la clase operativa propia de cada
        formulario en el proyecto del servicio web API bajo el modelo Entity Framework con el respectivo controlador.

               Los Proyectos son Tecnología .NET y Entity Framework cliente/servidor con servicio Web API
